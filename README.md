# Task Manager

A full-stack Task Manager application built as an internship assignment.

## Features

- Create Task
- View Tasks
- Edit Tasks
- Delete Tasks
- Search Tasks
- Dashboard Statistics
- Loading & Error Handling

## Tech Stack

### Frontend
- React
- TypeScript
- Vite
- Tailwind CSS

### Backend
- Node.js
- Express
- Prisma
- PostgreSQL

## Testing

### Backend
- Jest
- Supertest

### Frontend
- Vitest
- React Testing Library

## Run the Project

### Backend

```bash
npm install
npm run dev
```

### Frontend

```bash
npm install
npm run dev
```

## Status

All CRUD operations are implemented and tested.
